<h1 align="center" id="title">👁️Blackeyes</h1>

<p id="description">A quick and easy tool for running basic Paintest commands, designed for CTF participants</p>

<h2>🛠️ Installation Steps:</h2>

<p>1. Install by git repository</p>

```
sudo apt install git && git clone https://github.com/AdminWeayz/Blackeyes
```

<p>2. Make executable</p>

```
chmod +x blackeyes.sh
```

<p>3. Execute</p>

```
sudo ./blackeyes.sh
```
